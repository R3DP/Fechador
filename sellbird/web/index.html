O que é o Sellbird?

Sellbird é uma plataforma de prospecção de código aberto. Depois de configurado, o Sellbird funciona sozinho: encontra pessoas que correspondem ao seu cliente ideal, escreve e-mails frios personalizados, os envia pela sua plataforma de e-mail, lê cada resposta, lida com objeções, e trabalha para marcar uma reunião. Você revisa tudo por este painel.

O Sellbird roda na sua assinatura Claude Max (ou, se você optar, no seu plano ChatGPT via Codex), então não há custos extras de IA. Tudo fica na sua máquina, em uma única pasta.

Novidades e atualizações

Novos lançamentos, recursos e o roadmap são publicados primeiro no X: siga @sellbirdagent. Dúvidas e bugs vão para GitHub issues.

Primeiros passos

Há três coisas a fazer:

1. Vá à aba Configurações e conecte um provedor de e-mail (Gmail recomendado)
2. Treine o Sellbird no seu produto (pelo Claude ou pela linha de comando)
3. Vá à aba Controles e clique em Iniciar

A aba Hoje mostra exatamente o que já foi feito e o que ainda falta.

Onde tudo fica

Tudo o que o Sellbird precisa está dentro desta única pasta do projeto. Nada fica armazenado em outro lugar.

.envSuas chaves de API e credenciais (nunca compartilhadas ou commitadas)
sellbird.yamlInformações do seu produto, clientes-alvo, e configurações de comportamento
skills/Arquivos de conhecimento de vendas. Edite-os para mudar como o Sellbird escreve e vende.
skills/product_knowledge.mdTudo o que o Sellbird sabe sobre seu produto (gerado automaticamente a partir do treinamento)
prompts/Modelos de prompt para cada agente. Personalização avançada.
data/sellbird.dbBanco de dados com todos os prospects, campanhas e conversas
data/sellbird.logArquivo de log mostrando o que o Sellbird está fazendo

Obtendo suas chaves de API

Chave de API do Instantly (legado)

Instantly é a opção de envio legada; Gmail ou SMTP é recomendado.

1. Cadastre-se em instantly.ai (você precisa do plano Growth para acesso à API)

2. Vá em Settings > Integrations

3. Copie sua chave de API

4. Cole aqui na aba Configurações

Credenciais do LinkedIn (opcional)

Se você quiser que o Sellbird encontre prospects no LinkedIn, informe seu e-mail e senha do LinkedIn. O Sellbird usa um navegador real para pesquisar o LinkedIn como um humano faria, com atrasos aleatórios e limites de taxa para evitar detecção.

Se você pular isso, o Sellbird encontrará prospects por buscas no Google e varredura do site da empresa.

Cloudflare Browser Rendering (opcional)

Isso é usado apenas durante o treinamento de produto (quando o Sellbird rastreia seu site para aprender sobre seu produto). Lida com sites pesados em JavaScript que um rastreador básico não consegue ler.

1. Cadastre-se na Cloudflare (plano Workers pago, ~$5/mês)

2. Vá em Workers & Pages > Browser Rendering

3. Crie um token de API com permissões Browser Rendering Edit

4. Informe seu Account ID e API Token na aba Configurações

Sem isso, o Sellbird usa um rastreador embutido que funciona bem para a maioria dos sites, mas não renderiza JavaScript.

Problemas comuns

"command not found: sellbird"
Você precisa ativar o ambiente virtual primeiro: source .venv/bin/activate
A API do Instantly retorna 401
Sua chave de API está errada, ou você precisa do plano Growth (o plano gratuito não inclui acesso à API). Confira a chave em Settings > Integrations no seu painel do Instantly.
O modo headless do Claude falha
Certifique-se de ter rodado claude login no seu terminal e ter uma assinatura Claude Max ativa. O Sellbird usa sua assinatura existente, não uma chave de API separada.
Chamadas ao Codex falham
Com brain.provider: codex, defina brain.model como um ID de modelo disponível, incluindo Luna, Sol, ou Terra (por exemplo gpt-6.1-sol), ou deixe em branco para selecionar um modelo listado. O Sellbird roda esses modelos sem ferramentas; gpt-5.5 também continua suportado quando presente no catálogo da sua conta. Rode codex login e escolha "Sign in with ChatGPT" (logins por chave de API são recusados). O Sellbird nunca renova seu login do Codex: se o log disser que expirou ou precisa de renovação, use o Codex uma vez ou rode codex login. O Sellbird precisa do Codex CLI 0.159.3 no macOS ou Linux (Codex não é suportado no Windows; use o Claude lá) e recusa outras versões. Enquanto o Codex não pode ser usado, o Sellbird pausa (a aba Hoje mostra "Codex está pausado" e o motivo), deixa respostas e e-mails enfileirados intactos, e retoma assim que for corrigido; sellbird status --check verifica sob demanda. Se o log disser que o isolamento não pôde ser verificado, uma camada de configuração do Codex está forçando uma ferramenta, hook, servidor MCP ou endpoint personalizado de volta — o Sellbird recusa enviar prompts até que isso seja removido. O Sellbird nunca volta para o Claude por conta própria.
O Sellbird não está encontrando prospects
Verifique se o seu ICP (perfil de cliente ideal) em sellbird.yaml tem cargos, indústrias e geografia realistas. Se o LinkedIn estiver configurado, verifique se as credenciais estão corretas. Confira a aba Atividade para ver o que o Sellbird tem tentado fazer.
